# Roadmap

## Foundation

Stabilize startup, pairing, reconnect handling, structured logging, configuration validation, and safe shutdown.

## Professional operations

Add permission middleware, command registry, rate limiting, audit logs, health checks, and clear error responses.

## Feature platform

Convert moderation, greetings, anti-link, anti-delete, reactions, status automation, and media commands into independently testable plugins.

## Reliability and security

Add automated tests, linting, dependency updates, secret scanning, least-privilege owner controls, and recovery documentation.
